# Decisões arquiteturais

Esta pasta é reservada a Architecture Decision Records (ADRs). Um ADR registra uma decisão importante, seu contexto, alternativas consideradas e consequências.

## Convenção

Use nomes sequenciais no formato `NNNN-titulo-curto.md`. Depois de aprovado, um ADR não deve ser reescrito para alterar a decisão; publique um novo ADR que o substitua ou complemente.

## Template mínimo

```markdown
# ADR-NNNN — Título

- Status: proposto | aceito | substituído | rejeitado
- Data: AAAA-MM-DD
- Proprietário: equipe responsável

## Contexto

## Decisão

## Alternativas consideradas

## Consequências

## Referências
```
